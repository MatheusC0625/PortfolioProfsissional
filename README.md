Portfólio

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript.

Sobre

Projeto desenvolvido para apresentar minha trajetória, tecnologias, projetos e formas de contato como desenvolvedor.

Tecnologias

- HTML
- CSS
- JavaScript

Funcionalidades

- Hero com animação de partículas
- Interação da animação com o mouse
- Seção sobre
- Seção de projetos
- Marquee de tecnologias
- Links de contato
- Layout responsivo
- Suporte a redução de movimento

Como executar

Clone o repositório, abra a pasta, aperte no index com o botão esquerdo do mouse duas vezes, escolha o seu navegador e pronto, o projeto já deve aparecer no seu navegador.
